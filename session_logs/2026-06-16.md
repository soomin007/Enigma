# 2026-06-16 세션 로그

## 요약
전날 GitHub Pages 배포·저장소 재루트에 이어, 웹 빌드 실사용에서 드러난 문제들을 연달아 수정했다.
화면 크기/가독성, 클리어 연출 버그, 웹 특수문자 깨짐, 타이머까지 잡고 모두 라이브 반영·검증 완료.

## 주요 변경
- `project.godot`: 기준 해상도 **1920×1080 → 1280×720**, `window/stretch/mode="canvas_items"` + `aspect="keep"` 명시, `window/size/mode` 0(창).
  - canvas_items는 (창/기준해상도) 배율 → 기준을 낮춰 UI·글자를 ~1.5배 키움. 16:9 유지라 비율 그대로.
- `scripts/MainMenu.gd`: 메뉴 내용(타이틀+카드6+버튼5)이 720 세로를 넘쳐 잘림 → **ScrollContainer로 래핑**(짧으면 중앙정렬, 넘치면 스크롤). ⚙→◆, ✕(U+2715)→×(U+00D7) 글리프 교체.
- `scripts/ChapterView.gd`:
  - 완료 연출 1회 가드 `_completion_shown` + 오버레이 시 `gui_release_focus()` → **스페이스/엔터로 도장 애니메이션이 재생되던 버그** 해결.
  - 완료 연출 중 **스페이스·엔터 = 타자기 스킵**(클릭과 동일)로 지정.
  - 타이머 멈춤 가드 `is_level_complete` → `_completion_shown` → **이미 깬 레벨 재도전 시 멈춰 있던 타이머 실시간 복구**.
  - DECODED 도장: `ThemeDB.fallback_font`(★☆ 없음) → `get_theme_default_font()` → 별점 깨짐 해결.
  - 레드 헤링 라벨 ▸(U+25B8)→▶ 글리프 교체.
- `scripts/GameManager.gd`: `_setup_font_fallbacks()` 추가 — **NotoSansKR을 전 프로젝트 폰트의 fallback으로 등록**.

## 결정 사항
- **웹 특수문자 깨짐 근본 원인**: 데스크톱은 OS 시스템 폰트로 폴백되지만 **웹 export엔 폴백이 없어** 기본 폰트(NanumGothic)에 없는 글리프가 두부(□)가 됨. → NotoSansKR 폴백 등록으로 대부분 해결(★◆━→ 등).
- **폴백으로도 안 되는 글리프**(NanumGothic·NotoSansKR 둘 다 없음): ⚙ ✕(2715) ▸(25B8) → 안전한 기호(◆ × ▶)로 직접 교체.
- 해상도는 1280×720로 확정(사용자 요청 1.5배). 메뉴처럼 1080 기준으로 짜인 화면은 ScrollContainer로 흡수(요소 크기/위치는 보존).
- 게임 GUI를 이 환경에서 직접 실행해 시각 검증 불가(exe 실행 차단) → 사용자 피드백으로 씬별 검증.
