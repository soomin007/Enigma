  - main push 시 Godot 4.6.1 다운로드(캐시) → `Godot/1_Enigma` import → Web 프리셋 export → `actions/deploy-pages`로 Pages 배포

## 결정 사항
- **저장소 루트가 홈 디렉터리**라 `git add -A`/`.` 절대 금지 → 명시적 경로만 스테이징(.ssh·NTUSER.DAT 등 개인파일 보호).
- Web 프리셋 `thread_support=false` 확인 — GitHub Pages는 SharedArrayBuffer 헤더(COOP/COEP) 미지원이라 필수.
- 빌드 산출물은 `build/`로 내보내 `.gitignore`로 자동 무시(DEPLOY.md 철학) — 매번 루트 청소 불필요.
- 워크플로는 직접 Godot 바이너리+템플릿 다운로드 방식 채택(버전 명시·재현성). 기존 `enigma-export.yml`(태그 릴리스용)과 공존.
- `.tscn` ext_resource가 모두 `path=` 폴백을 가져 CI에서 UID 재생성돼도 로드 안전함을 확인.

## 세션 2 — 저장소 재루트 + 웹 화면 맞춤 + 제목 변경

### 요약
브라우저 탭 제목을 ENIGMA로 바꾸고, 웹 화면 잘림을 고치고, **저장소 구조를 프로젝트 폴더 기준으로 재루트**했다(GitHub 최상위에 README/project.godot 노출).

### 주요 변경
- `project.godot`: `config/name` → "ENIGMA"(탭/창 제목). `window/size/mode` 3(전체화면)→0(창), `window/stretch/mode=canvas_items` + `aspect=keep` 추가 → **웹에서 창 크기에 맞춰 자동 스케일**(잘림 해결).
- `image*.png` 6장 → `screenshots/`(서술적 이름) + `.gdignore`로 Godot import 제외, 옛 `.import` 삭제.
- `.github/workflows/` 를 프로젝트 내부로 이동, `deploy.yml`에서 `PROJECT_PATH` 제거(루트 기준), `enigma-export.yml` `relative_project_path: "./"`.
- README: 이미지 경로·클론 경로·구조 트리 갱신.

### 결정 사항 (중요 — 구조 변경)
- **근본 원인**: `.git`이 홈(`C:/Users/soomi`)에 있어 프로젝트가 `Godot/1_Enigma/` 접두사로 커밋됐음.
- **해법**: `git subtree split --prefix=Godot/1_Enigma`로 히스토리 보존하며 추출 → `enigma-root` 브랜치 → `git push -f origin enigma-root:main`. 이후 홈 `.git` 삭제, 프로젝트 폴더에서 `git init` + `git reset --hard origin/main`으로 독립 저장소화.
- **결과**: 저장소 루트 = `C:/Users/soomi/Godot/1_Enigma`, 홈은 더 이상 git 저장소 아님(이전의 `git add -A` 위험 영구 해소). 히스토리 20커밋 보존.
- 옛 release 태그(`enigma-v1.1.x`)는 원격에 남아 옛 구조 커밋을 가리킴 — 릴리스 기록이라 그대로 둠.
